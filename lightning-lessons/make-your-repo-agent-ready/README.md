## The premise

An agent meets your repository the way a new hire meets it on day one, except the agent reads faster and forgets everything by tomorrow. This lesson is a field guide to that interface, in three moves: **discover** what the agent actually sees (rules files, docs, project scripts), **act** by encoding your team's conventions where the agent will find them (soft rules in AGENTS.md, hard constraints in linters and type checks, docs that stay in sync), and **prove** the work with reviews where agents check other agents. The through-line: fix the repo once and every future run starts warm.
